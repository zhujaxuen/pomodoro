# Pomodoro

Timer Pomodoro em um único arquivo HTML: foco, pausa curta e pausa longa.

**Acesse o site: https://zhujaxuen.github.io/pomodoro/**

## Recursos

- Menu lateral com fundo, música e configuração de tempos
- Tempos configuráveis (padrão 25 / 5 / 15 min)
- Pausa longa a cada 4 pomodoros
- 10 fundos prontos, além da cor do modo, e envio de imagens próprias (até 8)
- Música do YouTube: cole o link de um vídeo ou playlist e use o player na página
- Opção de tocar a música no foco e pausar junto com o timer
- Contador diário, tarefa atual e configurações salvos no navegador
- Aviso sonoro e notificação ao fim de cada ciclo
- Atalho: barra de espaço inicia e pausa

## Como usar localmente

Abra o `index.html` no navegador. O player do YouTube pode não funcionar abrindo o arquivo direto do disco; use o site publicado.

## Publicação

O site é publicado com GitHub Pages a partir da branch `main`.
